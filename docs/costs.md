# CeroFallas — Registro de costos

Fecha de consulta: 2026-09-02

## Firebase Spark

Plan: Sin costo, sujeto a cuotas.

Motivo: Autenticación, base de datos y Hosting para el desarrollo inicial.

Costo estimado inicial: USD 0 mientras el consumo permanezca dentro de las cuotas y no se activen productos que exijan facturación.

Cuota gratuita relevante de Cloud Firestore publicada por Firebase:

- 1 GiB almacenado.
- 50,000 lecturas de documentos por día.
- 20,000 escrituras por día.
- 20,000 eliminaciones por día.
- 10 GiB de transferencia saliente por mes.

Límite configurado: Pendiente; no se habilitará facturación sin autorización explícita.

Estado: Propuesto para desarrollo inicial.

Fuentes:

- https://firebase.google.com/pricing
- https://firebase.google.com/docs/firestore/pricing

## Firebase Hosting

Plan: Spark inicialmente.

Motivo: Publicación HTTPS de la aplicación web.

Costo estimado inicial: USD 0 dentro de la cuota aplicable.

Estado: Pendiente de crear o vincular un proyecto Firebase.

Fuente: https://firebase.google.com/docs/hosting

## Cloud Functions, Cloud Run y Scheduler

Plan: Por evaluar durante la automatización e integración.

Motivo: Posible sincronización segura, tareas backend y ejecución predictiva.

Costo estimado: Pendiente del diseño y frecuencia. Algunos productos o usos pueden requerir el plan Blaze.

Estado: No autorizado para facturación.

## Cloud Storage for Firebase

Plan: Requiere Blaze según la documentación actual para proyectos nuevos.

Motivo: Evidencias fotográficas opcionales.

Costo estimado: Pendiente de volumen y región.

Estado: No se habilitará hasta recibir autorización expresa de facturación.

Fuente: https://firebase.google.com/docs/storage/web/start

## Power BI

Plan: El usuario informa que ya cuenta con una licencia para publicar reportes.

Costo incremental estimado: Pendiente de confirmar según modalidad de publicación y audiencia.

Estado: Disponible, sin configuración realizada.
